How it works
  1. First time: open Set up Google, follow the steps, then sign in once.
  2. Paste links to any spreadsheets that account can already edit.
  3. Edit columns if you want. Destructive edits warn you first and can be undone.
  4. Visit a job posting and click the extension icon to save.
  5. If sign-in fails, reopen Set up Google and use Common problems and fixes.
